# Implementation Plan: Drawing Canvas, Guessing & Scoring

**Branch**: `003-canvas-guessing-scoring` | **Date**: 2026-06-04 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/003-canvas-guessing-scoring/spec.md`

## Summary

Add a freehand drawing canvas for the drawer (native `<canvas>` API, fixed 600×400px), three new backend endpoints (`POST /stroke`, `POST /clear-canvas`, `POST /guess`), and extend `GET /rooms/:code` polling to include strokes, guesses, and scores. Wire the existing `GuessForm`, `Scoreboard`, and `ResultPanel` stub components to real data. Scoring: correct guess = 100 points (capped), incorrect = 0.

## Technical Context

**Language/Version**: TypeScript — Node.js 20 (backend), React 18 (frontend)

**Primary Dependencies**: Express + Zod (backend); React 18 + Vite (frontend) — no new packages; canvas via native browser API

**Storage**: In-memory only — `room.strokes`, `room.guesses`, `room.scores` on the existing `Room` object

**Testing**: Manual two-tab validation per constitution

**Target Platform**: Local dev — backend `localhost:3001`, frontend `localhost:5173`

**Project Type**: Web application (backend API + React SPA)

**Performance Goals**: Stroke rendering immediate on pointer events; guesser canvas lag ≤1 poll cycle (~2s)

**Constraints**: No new npm packages; no WebSockets; native `<canvas>` only; fixed canvas size 600×400

**Scale/Scope**: Single room, single round, small player count

## Implementation Phases

### Phase A — Backend model extensions

**A1. Extend `backend/src/models/game.ts`**
- Add `Point = { x: number; y: number }` interface
- Add `Guess` interface: `{ id, participantId, participantName, text, isCorrect, timestamp }`
- Extend `Room`: add `strokes: Point[][]`, `guesses: Guess[]`, `scores: Record<string, number>`
- Extend `RoomSnapshot`: add `strokes: Point[][]`, `guesses: Guess[]`, `scores: Record<string, number>`

**A2. Extend `backend/src/services/roomStore.ts`**
- In `startGame()`: initialise `room.strokes = []`, `room.guesses = []`, `room.scores = Object.fromEntries(room.participants.map(p => [p.id, 0]))`
- Add `addStroke(code, points)`: get room, guard playing status, push points array to `room.strokes`, `saveRoom()`
- Add `clearCanvas(code)`: get room, guard playing status, set `room.strokes = []`, `saveRoom()`
- Add `submitGuess(code, participantId, text)`: get room, guard playing status, find participant name, evaluate `text.trim().toLowerCase() === room.currentWord?.toLowerCase()`, build `Guess` object, push to `room.guesses`, if correct and `room.scores[participantId] < 100` set score to 100, `saveRoom()`, return guess + score
- Update `toRoomSnapshot()`: include `strokes`, `guesses`, `scores` (no per-viewer filtering needed)

**A3. Add schemas in `backend/src/api/schemas.ts`**
- `strokeSchema`: `z.object({ points: z.array(z.object({ x: z.number(), y: z.number() })).min(1) })`
- `guessSchema`: `z.object({ participantId: z.string().min(1), text: z.string().min(1) })`

**A4. Add routes in `backend/src/api/rooms.ts`**
- `POST /:code/stroke` → parse params + body, call `addStroke()`, return `{ ok: true }` or 404/409
- `POST /:code/clear-canvas` → parse params, call `clearCanvas()`, return `{ ok: true }` or 404/409
- `POST /:code/guess` → parse params + body, call `submitGuess()`, return `{ guess, score }` or 404/400/409

### Phase B — Frontend types + API client

**B1. Update `frontend/src/services/api.ts`**
- Add `Point` and `GuessSnapshot` interfaces
- Extend `RoomSnapshot`: add `strokes: Point[][]`, `guesses: GuessSnapshot[]`, `scores: Record<string, number>`
- Add `addStroke(code, points)`: `POST /rooms/:code/stroke`
- Add `clearCanvas(code)`: `POST /rooms/:code/clear-canvas`
- Add `submitGuess(code, participantId, text)`: `POST /rooms/:code/guess`

**B2. Update `frontend/src/state/roomStore.ts`**
- Add `addStroke(points)` action: calls `api.addStroke(room.code, points)`
- Add `clearCanvas()` action: calls `api.clearCanvas(room.code)`
- Add `submitGuess(text)` action: calls `api.submitGuess(room.code, participantId!, text)`

### Phase C — DrawingCanvas component (new)

**C1. Create `frontend/src/components/DrawingCanvas.tsx`**
- Props: `strokes: Point[][]`, `isDrawer: boolean`, `onStroke: (points: Point[]) => void`, `onClear: () => void`
- Fixed 600×400px `<canvas>` with a `useRef`
- `useEffect` on `strokes` prop: `clearRect(0,0,600,400)` then replay all strokes as polylines
- When `isDrawer`: attach pointer event handlers for drawing; collect points on move; call `onStroke` on mouseup/touchend
- When not drawer: no event handlers attached
- "Clear Canvas" button only rendered when `isDrawer`

### Phase D — Wire existing components

**D1. Update `frontend/src/pages/GamePage.tsx`**
- Replace canvas placeholder `<div>` with `<DrawingCanvas>`
- Wire `onStroke` → `roomStore.addStroke(points)`
- Wire `onClear` → `roomStore.clearCanvas()`
- Pass `disabled={isDrawer}` to `<GuessForm>` and hide it entirely for drawer
- Pass `participants={room.participants}` and `scores={room.scores ?? {}}` to `<Scoreboard>`
- Pass `guesses={room.guesses ?? []}` to `<ResultPanel>`

**D2. Wire `frontend/src/components/GuessForm.tsx`**
- Add props: `onSubmit: (text: string) => Promise<void>`, keep `disabled: boolean`
- On submit: trim, if empty show "Guess cannot be empty" error inline; else call `onSubmit(text)`, clear input

**D3. Wire `frontend/src/components/Scoreboard.tsx`**
- Add props: `participants: Participant[]`, `scores: Record<string, number>`
- Render rows sorted by score descending: participant name + score

**D4. Wire `frontend/src/components/ResultPanel.tsx`**
- Add prop: `guesses: GuessSnapshot[]`
- Render in chronological order: participant name, guess text, ✓/✗ indicator

### Phase E — Validation

- Two-tab test: draw strokes, clear, submit correct/wrong/empty guesses
- Verify guesser canvas updates within ~2s; scoreboard and history update on both tabs
- `npm run build` in `backend/` and `frontend/` — both must pass

## Key Invariants

1. Guesser canvas fully replays all strokes on each poll (clear + redraw) — no incremental diffing.
2. `scores` is `Record<string, number>` (plain object) — `structuredClone` in `saveRoom()` handles it correctly.
3. `GuessForm` is hidden entirely for the drawer in `GamePage` (not just disabled).
4. Score cap enforced on backend: only set to 100 if `room.scores[participantId] < 100`.
5. `POST /stroke` and `POST /clear-canvas` both guard `room.status === "playing"` → 409 otherwise.
